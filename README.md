# Kadro

Бесплатный видеоредактор для Android: без подписок, рекламы, аккаунтов и водяных знаков.
Оригинальная разработка — свой интерфейс, свой код, движок на AndroidX Media3.

**Скачать:** [`dist/Kadro.apk`](dist/Kadro.apk) (Android 10 и новее, ~4 МБ).
На телефоне: откройте файл и разрешите установку из этого источника.

## Что умеет

- Проекты из нескольких видео и фото, автосохранение черновиков
- Таймлайн с миниатюрами: разрезать, обрезать края (ручки на выбранном клипе), дублировать, менять порядок, удалять
- Скорость 0.25×–4×, громкость клипа 0–200 %, отключение звука
- 9 цветовых фильтров, яркость / контраст / насыщенность
- Кадр: вписать или заполнить, приближение, поворот на 90°, зеркало
- Переходы: появление из чёрного и затухание в чёрный
- Текст: цвет, размер, жирность, обводка или плашка, время показа; двигается пальцем прямо в превью
- Музыка поверх видео: громкость, начало трека, повтор по кругу
- Формат холста: 9:16, 16:9, 1:1, 4:5, 3:4 или как в первом клипе
- Отмена и возврат действий
- Экспорт MP4 (H.264 + AAC) 480p / 720p / 1080p / 4K в галерею, папка `Movies/Kadro`
- «Открыть в Kadro» и «Поделиться в Kadro» из других приложений

## 4K, HDR и тяжёлые ролики

В телефоне обычно всего один-два аппаратных декодера, которые тянут 4K, а редактору их нужно
несколько одновременно: превью, кадры таймлайна, следующий клип. Поэтому для каждого клипа
в 4K, с частотой выше 60 к/с или в HDR Kadro один раз делает лёгкую рабочую копию 720p
(на экране — «Готовим 4K-видео к монтажу»). Монтаж идёт по копии, а экспорт всегда берёт
оригинал, так что качество не теряется. HDR-съёмка переводится в обычный цвет (SDR).

Копии лежат во внутренней памяти приложения и удаляются вместе с черновиком.

## Если приложение закрылось с ошибкой

При следующем запуске на главном экране появится карточка с причиной. Нажмите
«Скопировать отчёт» и пришлите текст разработчику: там модель телефона, версия Android и то,
что происходило в момент сбоя.

## Сборка из исходников

Нужны JDK 17+ и Android SDK (platform 36, build-tools 35).

```
gradle :app:assembleRelease
gradle :app:testDebugUnitTest   # проверки модели проекта
```

APK появится в `app/build/outputs/apk/release/`. Сборки подписываются открытым демо-ключом
`kadro.keystore` из репозитория, чтобы обновления ставились поверх. Для публикации в магазине
замените его своим ключом.

## Устройство кода

| Файл | Назначение |
| --- | --- |
| `Model.kt` | Проект, клипы, текст, музыка, фильтры, JSON |
| `Engine.kt` | Проект → композиция Media3 (общая для превью и экспорта) |
| `Session.kt` | Открытый проект: история, плеер, экспорт |
| `Media.kt` | Чтение файлов, миниатюры, черновики, сохранение в галерею |
| `Proxies.kt` | Лёгкие рабочие копии 4K/HDR-клипов |
| `CrashLog.kt` | Отчёт о последнем сбое |
| `Editor.kt`, `Timeline.kt`, `Panels.kt`, `Ui.kt` | Интерфейс на Jetpack Compose |
